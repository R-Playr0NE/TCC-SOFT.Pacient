# 🏥 SOFT-Pacient (ou [Nome do Projeto])
> **Sistema de Otimização de Fluxo e Tempo para Pacientes em Postos de Saúde**

Este projeto é um **Trabalho de Conclusão de Curso (TCC)** desenvolvido com o objetivo de modernizar a gestão de atendimento na rede pública de saúde (UBS e Postos Clínicos), eliminando as filas de espera físicas e combatendo a superlotação através de uma solução de **Fila Inteligente**.

---

## 🎯 Objetivo do Projeto

O sistema visa inibir e amenizar os maiores problemas presentes nas clínicas e postos de saúde, com foco nas grandes filas e na superlotação. A proposta atua como uma atualização dos sistemas clínicos existentes, introduzindo ferramentas de monitoramento remoto:

*   **Fila Inteligente:** Calcula o tempo médio de espera com base na posição atual do paciente e na média de tempo de cada consulta.
*   **Notificações em Tempo Real:** Alertas no smartphone do usuário notificando alterações de posição ou eventos especiais (como a entrada de casos urgentes nas classificações de risco Vermelha ou Laranja).
*   **Otimização do Espaço Físico:** O paciente aguarda no conforto de sua residência e só se desloca à unidade quando estiver entre os 5 primeiros da fila, liberando o espaço hospitalar para casos graves e emergenciais.

---

## 🛠️ Tecnologias Utilizadas

O ecossistema do projeto foi construído utilizando as seguintes ferramentas e linguagens:

### Back-End
*   **Java** (Linguagem principal)
*   **Spring Boot** (Framework para API REST)

### Front-End
*   **HTML / CSS / JavaScript / TypeScript**

### Banco de Dados
*   **PostgreSQL** (Banco de dados relacional)
*   **pgAdmin3 / pgAdmin4** (Gerenciador de banco de dados)

### Engenharia e Modelagem
*   **UML** (Diagramas de Caso de Uso / Use Cases)
*   **DER** (Diagrama de Entidade-Relacionamento)
